# macOS · Jellyfin 媒体库排版与详情页开发任务

基线为 OpenFuse v0.6.0（36599b0）。目标是在 OpenFuse 的 Jellyfin 直连入口修好卡片越界，并让用户在同一页选集、读剧情与评分、查看演职员和所选文件的技术参数。

## 先修网格

从 [JellyfinView.swift](../../../Sources/OpenFuseApp/JellyfinView.swift) 的 JellyfinBrowserView.card 开始。当前库、影片和集共用自适应网格和 2:3 图片容器；成功载入的 AsyncImage 使用 fill。先在真实窗口观察图片载入前后的列宽、渲染边界与按钮命中范围。由网格单元决定卡片宽度，分别给库入口和分集使用横图（建议 16:9）、电影和剧海报使用竖图（建议 2:3）。图像、占位、加载失败及选中覆盖层共用同一固定比例容器，填充后在容器内裁剪。文字和焦点框对齐本列，长标题能换行或截断。验证间距处不会误点相邻卡片。UserView 按服务端实际可浏览能力处理，显示中文名称或省略重复副标题。

## 作品详情与选集

沿用现有 Jellyfin 浏览导航，将 Series、Season、Episode、Movie 的详情接入窗口主内容区。当前 Series/Season 直接下钻目录，可播放项弹出固定宽度 640 pt 的 sheet。目录和合集保留原有浏览语义。

- 顶部 Hero 使用作品或父剧集的 Jellyfin Backdrop；缺图时回退至可用封面配色或主题底色。标题、剧情、播放／继续观看、片长、日期、类型和分级在亮暗主题及窄窗均可读。宽度不足时让说明文字移到横幅下。
- 电视剧按季选择，分集使用横向缩略图，显示集号、标题、当前选择及观看进度。单击选择集数后，就地更新本集标题、概要、资料、播放目标与参数。点“播放”才启动播放器。从单集直接进入应定位到正确季集。退出播放后恢复原选集与滚动位置。电影使用同一详情框架，展示电影信息。
- 评分标明来源、对象及原分制。以 Jellyfin 的 CommunityRating、CriticRating 与现有可用的外部评分为输入；ProviderIds 只用于关联。影评分与观众分分别标识，整剧评分归属整剧。尊重已有防剧透设置。
- 演职员按 Jellyfin People 的实际数据展示头像、姓名和角色／职务，至少区分演员和导演。无头像显示占位，缺少单集人员时明确标注所展示的是整剧演职员。

## 文件技术参数

在播放按钮附近提供一行可换行的摘要，顺序为文件大小、视频编码、分辨率、音频编码与声道、总码率、帧率。“媒体信息”可展开查看容器、实际宽高、编码 profile、位深、动态范围、音轨语言和字幕格式。按当前单集、选中的 MediaSource.Id 与实际选择或默认的流取值；切换版本后一起刷新播放目标与参数。声道布局、HDR、码率单位及帧率以真实字段为准。总码率与单条视频流码率分别标识，文件大小与平均码率严格区分，未知字段省略。

在 [Jellyfin.swift](../../../Sources/OpenFuseData/Jellyfin.swift) 与 [AppModel.swift](../../../Sources/OpenFuseApp/AppModel.swift) 扩展必要的可选字段和图片类型。复用现有版本选择、播放会话及进度处理。列表请求保持轻量，选中条目后再获取详情、媒体源和人员资料。图片和资料异步载入，快速切集时取消旧请求或校验返回的 item/source ID。评分服务或图片失败时，保留已经可用的浏览和播放操作。

## 完成条件

1. 用实际 Mac 窗口复现前两张截图中的问题。用横幅、竖海报、超宽图、无图、长中文标题在窄窗、常用宽度和全屏检查。提交修复前后对照图，并点击各列及其间距验证命中范围。
2. 在“百度网盘电视剧 → 冰血暴”切季，并依次选 S01E01 和 S01E02，验证横幅、分集、评分归属、演职员、技术参数和播放目标一致。再验证一部电影、多版本样片及缺图／缺评分条目。
3. 对开发夹具设置可核对的文件大小、HEVC 1080p、AAC 5.1、总码率和 24000/1001 fps。对照原始数据检查单位与帧率显示。快速切集、切版本后，迟到的响应不能覆盖当前选择。
4. 运行现有测试，补字段解码和参数格式化回归测试。交付可安装的 Mac ZIP、升级命令、提交号与真实窗口截图。证据使用脱敏的数据和路径。
