# 0.9.2 · WebDAV 文件夹名与紧凑浮动播放器

基线 0.9.1（`04b0160`）。本轮只改 macOS 界面与相关纯函数，播放仍由既有 mpv 会话负责。

## 1. WebDAV 文件夹显示名

### 问题

`BrowserView.card(_:)` 与 `singleSeasonPoster` 把整条 `entry.path` 传给 `RemotePath.displayName(_:)`，而后者接收的是单个面包屑。目录卡片因此显示 `local/kaiwenyao/baidu/电视剧/Fargo (2014)` 这类整条路径，而不是 `Fargo (2014)`。

### 规则

`Sources/OpenFuseData/RemotePath.swift`：

```swift
public static func folderDisplayName(name: String, path: String) -> String
```

1. 去掉首尾空白；若 `name` 是有效的单段（非空、非 `.`/`..`、不含 `/`），使用它。
2. 否则从已经解析好的 `path` 取最后一个非空路径段。
3. 不再次做百分号解码；`path` 已由 `WebDAVClient.decodePath` 解码一次。
4. `RemoteEntry.folderDisplayName` 是对外统一入口。

同时增加 `RemoteEntry.baseName` / `fileBaseName`：当服务器把整条路径放进 `<displayname>` 时，NFO 探测、外挂字幕匹配和播放标题使用 `path` 的最后一段，而不是把整条路径当文件名再次拼接。

### 使用位置

- 网格：`BrowserView.card(_:)`
- 列表：`BrowserView.row(_:)`
- 单季卡副标题：`BrowserView.singleSeasonPoster`
- VoiceOver：`BrowserView.entryAccessibilityLabel(_:)`，卡片/行按钮的 `.accessibilityLabel`
- 面包屑：继续使用 `RemotePath.displayName(pathStack[index])`，父目录只在这里出现

`entry.path`、`entry.url`、`entry.id` 未改变，仍用于请求、导航和缓存。

### 测试

- `RemotePathTests`：中文、空格、括号、尾斜杠、字面 `%`、同名 `Season 01`、整条路径 displayname、URL/path 身份不变。
- `WebDAVTests`：路径型 displayname 的 PROPFIND 列表、外挂字幕匹配、百分号解码边界。

## 2. 浮动播放器面板

### 几何

`Sources/OpenFuseCore/FloatingPanelMath.swift`：

- `panelWidth(containerWidth:)`：普通窗口上限 560；500 pt 窗口为 476；320 pt 窗口为 304。
- `panelHeight(compact:)`：普通 94；小窗 82。
- `baseOrigin`：水平居中、顶部 64 pt（小窗 54 pt），给标题条和底部字幕留空间。
- `clampedOffset`：拖动后把整个面板限制在窗口内（边缘 8 pt），窗口缩放/全屏后重新钳制。
- `previewOpensDownward(panelOriginY:)`：面板顶部时缩略图向下，拖到画面中部后向上。

### 标题

`Sources/OpenFuseCore/PlayerHeading.swift` + `MediaItem.seriesTitle`：

- 顶部只显示作品名与季集号，例如 `Fargo (2014)` / `S01E01 · The Crocodile's Dilemma`。
- 支持本地文件名、WebDAV/Jellyfin 标题、没有季集信息的电影。
- 完整文件名、来源、编码、分辨率、音轨、字幕、速度、时长、缓存和日志在「播放信息」弹出层。

### PlayerChrome

`Sources/OpenFuseApp/PlayerView.swift`：

- 两行面板：第一行运输控制（播放/暂停居中，快退/快进两侧，音量/选集/字幕/更多分列），第二行独占时间轴，显示已播时间与剩余时间。
- 320 pt 小窗：字幕入口在左，播放/快退/快进居中，「更多」在右；音量收进菜单。
- 面板顶部 10 pt 空白拖动条负责拖动，避免拖动音量/时间轴时误拖面板。
- 悬停面板、字幕弹层、键盘操作（`noteKeyboardActivity`）、拖动时间轴通过 `PlayerModel.setChromeHold` 保持可见；空闲后 3.2 秒淡出。
- 缩略图沿用 `PlayerScrubber` 的缓存区间、拖动和 `ThumbnailProvider`；`previewBelow` 控制弹出方向。
- macOS 26+：`glassEffect(.regular, in:)` + 18% 黑色 tint；macOS 14/15：`NSVisualEffectView(material: .hudWindow, blendingMode: .withinWindow)`；`accessibilityReduceTransparency` 为真时使用不透明深色面板。
- 顶部标题条：`ultraThinMaterial` + 52% 黑色胶囊，避免明亮视频文字透出。
- 控件继续绑定同一 `PlayerModel`；mpv 负责画面、声音和字幕。

### 交互细节

- 面板只在实际绘制的区域接收点击；空白视频区域仍可触发鼠标活动、右键暂停等既有行为。
- 面板位置在窗口缩放、⌘3 最大化、原生全屏后重新计算并钳制。
- 右键暂停、↑/↓ 音量、Esc 退出、返回来源后恢复原季/选集均保持原行为。
- 字幕弹层保留整行选轨、勾选、hover 高亮、提前/延后 0.1 秒、输入秒数和重置。

### 测试

- `FloatingPanelTests`：宽度、默认位置、拖动钳制、窗口缩放、预览方向。
- `PlayerHeadingTests`：作品名/季集号、文件名前缀、Jellyfin 风格集名、空白清理。
- 运行报告（`delivery/evidence/`）记录 `panelOrigin`、`panelSize`、`panelContainer`、`chromeHolds`、`showControls`、`subDelay`。
- 录屏 `delivery/recording/panel-interaction.mp4`：拖动 → 悬停预览 → 字幕偏移 → 自动隐藏。

## 3. 验收辅助

本轮新增的应用内验收开关（仅用于本地 UI 测试，不影响正常用户路径）：

- `--capture-window <png>`：抓取自身窗口（含视频层）。
- `--capture-screen <png>`：抓取屏幕区域，可包含字幕弹层等独立窗口。
- `--record-window <dir>` / `--record-screen <dir>`：按帧记录窗口/窗口区域，供 ffmpeg 合成录屏。
- `OPENFUSE_SUBTITLE_MENU_AFTER`、`OPENFUSE_SUBTITLE_OFFSET_AFTER`、`OPENFUSE_SUBTITLE_MENU_CLOSE_AFTER`：定时打开/修改/关闭字幕弹层，用于可重复录制。
- `OPENFUSE_HOVER_SCRUBBER`、`OPENFUSE_HOVER_SUBTITLE_ROW`：缩略图/字幕行悬停验收。

报告新增字段：`headingTitle`、`headingDetail`、`showControls`、`chromeHolds`、`panelOrigin`、`panelSize`、`panelContainer`。
