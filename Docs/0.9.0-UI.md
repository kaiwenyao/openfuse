# OpenFuse 0.9.0：macOS 浏览与播放界面改版

- `MainShellView`：可收起 macOS 侧边栏（首页/媒体库/文件、搜索、添加来源、设置）；播放器绕过侧边栏。
- 首页只显示最近 4 项继续观看；媒体库独立承载搜索/筛选/排序；文件页独立承载 WebDAV/Jellyfin/Plex/SMB 来源。
- WebDAV：默认网格 + 列表切换；普通目录文件夹图标/名称；单季目录显示 2:3 季海报；季详情页含当前集、横向剧照、播放/技术摘要，支持选择 E02 后播放并持久化。
- Jellyfin 详情沿用 Hero/分季/选集/评分/演职员/技术参数，并与 WebDAV 共用导航壳和视觉层级。
- 播放器：底部控制改为居中深色浮动面板；进度条独占一行；新增上一集/下一集；320 pt 使用紧凑面板。
- 保留字幕偏移（整行 popover）、进度条预览、续播、⌘3 最大化、⌃⌘F 全屏、右键暂停/音量。
- 117 个单元测试；player-ui、thumbnail、window、Jellyfin、three-features 回归通过。
