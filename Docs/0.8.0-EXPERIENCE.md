# OpenFuse 0.8.0：整行字幕菜单、⌘3 最大化、资料语言与缩略图缓存

## 1. 字幕菜单整行
- `SubtitleMenuRow`：Button label 内 `frame(maxWidth:.infinity)` + 横/纵内边距 + `contentShape(Rectangle())`；悬停 `onHover` 整行背景；选中勾选；禁用行 `.disabled` 不响应。
- 关闭字幕、字幕轨、提前/延后/输入/归零共用行组件；VoiceOver 标签/选中 trait 保留。
- 验收截图：`build/0.8.0/subtitle-hover.png`（强制定格 hover 用于截图；真实鼠标点击在该 AX 环境未成功注入，见限制）。
- 真实鼠标左/中/右点击的坐标命中由完整宽度 label 保证；本轮未能用系统级鼠标事件完成三处点击录制。

## 2. ⌘3 最大化
- `AppModel.maximizePlayerWindow()` 使用 `window.screen.visibleFrame` 设置外框；不改变 `styleMask.fullScreen`。
- 从原生全屏：监听具体 NSWindow 的 `didExitFullScreenNotification`，收到后再次调用最大化，避免 key window 在过渡期间变化。
- `Scripts/run-window-management.sh` 已改为验证 frame==visibleFrame、isFullScreen=false、连续 ⌘3、全屏→最大化；Esc 仍用 ⌃⌘F 后 Esc。
- 实测：windowFrame `{{0,0},{1454,948}}`，visibleFrame 同值；fullScreen false。副屏无硬件，未实测。

## 3. 语言
- `MetadataLanguage.current` 读取 `AppleLanguages`/系统首选；zh-Hant/Hans、地区变体、ja 等。
- Wikipedia MediaWiki API 使用 `variant=zh-hans/zh-hant`；中文标题从本地化 extract 的《…》提取；Bangumi 公开 API 提供中/日集名；日文 desc 不作为中文剧情。
- 字段级：中文集名 + 英文简介（`titleLanguage=zh-Hans, overviewLanguage=en`）；缺失字段回退英文，不覆盖已有中文标题。
- 缓存键含语言：`sourceID-language-kind-title-season`，同一 support 从 zh-Hans 切 zh-Hant 得到新结果，两套缓存共存。
- 实测：AoT S01E01/E02 中文/Hant/日文集名与剧照；Inception/Interstellar 中文标题“盗梦空间/星际穿越”；`defaults AppleLanguages` 切换生效。
- Jellyfin 使用服务器已返回的数据，不改服务端；未实现按需机器翻译。

## 4. 缩略图
- `ThumbnailProvider` 新增 `ThumbnailCache` 磁盘文件、80 项 LRU 内存缓存、稳定 FNV 键（媒体指纹+bucket），配置换片不清磁盘；`cachedOrDiskImage` 异步读盘。
- `PlayerScrubber` 悬停先显示准确时间，内存/磁盘命中不经过 120 ms 防抖；未命中才进入抽帧，清除旧图避免误导。
- 报告中新增 `thumbnailLastSource/ElapsedMs/DiskHits/Benchmark*`。
- 本地冷：P50 166 ms / P95 205 ms（15 冷 + 15 热，热 P95 0 ms）；重启后磁盘：P50 0 ms / P95 1 ms（15 次全 disk hit）。
- 未实现 Jellyfin Trickplay 图集与后台预取合并；现有独立解码器仍按需抽帧，未 seek 主播放器。
