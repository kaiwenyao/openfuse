# OpenFuse macOS 界面改版 · 开发提示词

在 OpenFuse 仓库当前分支实现下面的 macOS UI。交接基线为 0.8.3（`7ec675a`）。请实际启动应用，走通浏览和播放，再交付可安装产物。本文已把九张参考图转成独立规格，实施所需的页面、数据和验收场景均在下文。

用户最常走的路径是「文件 → OpenList → 电视剧 → 某部剧 → 某一季 → 选集 → 播放」。让用户在每一步都看得出自己在哪里、选中了什么，以及点播放会打开哪个文件。作品图片是浏览时的主角，播放时则把画面让给视频。采用 OpenFuse 自己的蓝色、系统字体和 SF Symbols，做出有区别的导航、卡片和播放控制设计。作品美术来自用户连接的媒体来源或项目已有的合法元数据渠道。

## 1. 首页、媒体库和文件各有明确入口

- 浏览窗口使用可收起的 macOS 侧边栏。顶部放搜索，下面是「首页」「媒体库」「文件」。沿用现有搜索能力，说明搜索范围，能够打开结果并返回原位置。右侧工具栏显示当前标题、可用时的返回按钮，以及与该页有关的动作。「添加来源」放在文件页，「排序／筛选」放在媒体库。保留已有设置和来源管理入口。
- 首页首先显示最近的继续观看卡片，沿用最多四项、真实缩略图、进度及「查看全部」。点击仍立即进入播放加载页。媒体库负责按作品浏览、搜索和筛选。文件页按实际连接列出 OpenList/WebDAV、Jellyfin，以及用户已配置的其他来源。
- 来源只有三项时从左开始排列，余下空间自然留白。每张卡有易识别的图标和用户给它的名字，整张可点。窄窗口可收起侧边栏，返回上一层时恢复来源、选择和滚动位置。进入播放器后使用完整的播放区域。

## 2. 从普通文件夹自然过渡到作品

- 文件页和 WebDAV 的目录页默认网格浏览，同时提供紧凑列表。目录示例为 `baidu`、`subtitle`、`videos`。普通目录显示文件夹图标和真实名称。项目多时自动换行，长标题截断后可查看全名。网格列宽由容器决定，下载中的图、占位图、标题和点击区域都约束在同一个单元格内。
- 进入「电视剧」时按实际目录列出作品。进入已高置信匹配的单季目录，例如 `Fargo (2014)/Season 01`，主视图展示一张带剧名和季号的 2:3 海报，点击进入该季详情。聚合只改变显示。用户可切到「查看文件」访问本季所有原始视频、外挂字幕、不同压制版本和手动匹配。混合目录逐项呈现，无法匹配的文件仍可直接播放。多个版本必须能选择到具体文件。
- WebDAV 列目录与补资料异步进行，返回或快速换目录时丢弃迟到结果。避免为绘制一屏目录而逐个递归枚举网盘或打开视频。Jellyfin 沿用现有的库、剧、季和单集标识。

## 3. WebDAV 和 Jellyfin 共用一套作品详情布局

- 详情在当前内容区纵向滚动，顶部保留导航。首屏使用宽幅剧照或背景图，给图片设高度上限，让当前选集和「播放／继续播放」在常见笔记本窗口内可见。只有竖海报时，可用独立海报配主题底色。无图时标题和播放入口仍然完整。浅色和深色外观下，明亮或复杂剧照都应有可靠的文字对比度。
- 在大图与正文的交界放作品标题和播放主操作。紧接着显示当前集的季集号、集名、日期、时长、分级、类型、简介和有来源的评分。宽窗可分栏，窄窗顺排。用 OpenFuse 的文字层级、小型来源标签和蓝色选中态组织信息。只显示可执行的次要动作，低频操作收进「更多」。
- 下方是季选择和可横向浏览的 16:9 分集剧照带。卡片显示集号、集名、当前选中态和已有观看进度。单击另一集只更新详情，明确点击播放才打开选中的集及版本。支持触控板、键盘和可见的翻页操作。以文件或服务器实际存在的剧集为可播集合，资料库中多出的集数不能变成虚假播放按钮。电影直接呈现作品及版本。
- 接着显示演职员横栏。演员展示姓名和角色，主创展示姓名和职务。缺头像用统一占位，缺整段资料时收起。评分标注来源、量表及所属作品或单集。底部左侧显示来源和文件名，右侧用一行列出文件大小、视频编码、分辨率、音频编码及声道、码率和帧率。窄窗允许换行，完整参数沿用可展开的媒体信息。切换版本后参数与播放目标一同更新。
- 用两种真实情况校验页面。《冰血暴》第一季可有缺少剧照的单集和缺头像的人物。《性爱自修室》第一季有八集，剧照和人像较齐。两页应使用同一布局，留白随实际资料自然变化。WebDAV 的可选人物与文件字段按来源能力映射，优先使用已有匹配结果、缓存及已探测值。按需取数，遵循现有语言回退和防剧透设置。

## 4. 播放器改成轻量浮动控制面板

- 黑色播放画布占满内容区。窗口顶部保留关闭／返回入口与当前标题。鼠标活动时，在上方中央显示窄于窗宽的深色半透明控制面板。空闲时淡出，操作弹窗、拖动或键盘聚焦时保持可见。使用 OpenFuse 自己的间距、图标组合和焦点样式。
- 面板中区分音量、上／下一集、快退／快进、播放／暂停、全屏与选集。进度条独占一行。悬停预览始终留在窗口内，顶部空间不足时调整预览位置。320 pt 小窗优先保留播放、进度和可展开的其他控件。音轨、字幕偏移、速度、缓冲状态、输出设备等已有入口均须可达。尤其保留画面底部能直接打开的字幕入口、整行 hover 和点选，以及手动输入偏移秒数。
- 接回已有 mpv 播放器、PlayerScrubber 和 ThumbnailProvider，保留视频本身的表面和解码会话。切集、拖动时间线、导航回上一页、右键暂停、↑↓ 调音量、⌘3 最大化窗口、⌃⌘F 原生全屏都要按既有行为工作。

## 5. 代码落点和验收

- 从 `Sources/OpenFuseApp/HomeView.swift` 的 `RootView`、`HomeView` 和 `AppModel.swift` 的 `AppRoute` 入手。首页目前叠放历史、媒体库和来源。把这些现有入口拆到合适的侧边栏目的地，并处理播放返回路由。主题沿用 `Theme.swift` 的蓝色和动态色板，文字使用 macOS 系统字体。可用 8 pt 间距节奏，浏览内容左右留 20–28 pt。技术数据和时间使用等宽数字。
- `BrowserView.swift` 的 WebDAV 文件列表和固定 680 × 600 的资料浮层需要改成可导航页面。`JellyfinView.swift` 和 `JellyfinDetailPage.swift` 已有分季、选集、版本、评分、演职员和技术摘要。提取能共用的视图，保留各来源独立的取数、鉴权和播放逻辑。`LibraryView.swift` 的已有资料编辑、合并及播放入口继续可达。播放器视觉改动集中在 `PlayerView.swift` 及已有控制组件。
- 至少实际走通「来源 → 三个普通文件夹 → 多部剧目录 → 单季海报 → 选择 E02 → 播放 → 返回同季 E02」和「Jellyfin → 电影 → 切换版本 → 检查参数 → 播放」。再测首页续播、原始文件列表、缺图、慢网、长中英文标题、侧边栏收起、浅／深色及键盘焦点。浏览以当前支持的最小窗口和宽窗口验收。
- 使用项目现有构建和测试脚本。为新导航更新受影响的 UI 测试，从应用正常入口点击，核对实际播放的条目与版本。以 OpenFuse 自身的运行截图交付来源页、目录网格、单季页、详情首屏及滚动后、播放器控制和预览。交付改动摘要、已验证结果、仍待验证项、macOS 安装包路径和安装命令。
