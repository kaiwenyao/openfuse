# OpenFuse 0.7.0：字幕偏移、零配置资料、继续观看与加载页

## 1. 底栏字幕偏移

- `PlayerView` 底部字幕 `Menu` 在轨道列表后增加：当前值、提前/延后 0.1 秒、输入秒数、重置；`selectedSubtitleID == nil` 时保留菜单但禁用四个调节项。
- 顶部菜单与底栏共用 `PlayerModel.adjustSubtitleDelay/setSubtitleDelay/beginSubtitleDelayInput/resetSubtitleDelay`；正值延后。
- 偏移由 `SubtitleOffsetStore` 按视频指纹 + 字幕轨持久化；现有 `--sub-delay` 和三功能回归验证写入、恢复与 ASS 外挂。

## 2. 零配置 WebDAV/Jellyfin 资料

- 设置不再出现 TMDB/OMDb key 输入、保存、验证或提示；正常启动不读取 Keychain 资料 key。
- Jellyfin 直接使用 `Items`/`PlaybackInfo` 返回的标题、集号、简介、社区/影评人评分、People 与图片。
- WebDAV `RemoteMetadataService` 不再因缺少 TMDB 提前返回；先读当前目录/剧集父目录 `tvshow.nfo`/`movie.nfo`/视频同名 NFO 与相对海报，再走公共服务：
  - 剧集：TVmaze 搜索 + 分集；Wikipedia（zh 优先，en 回退）补中文标题/简介；TVmaze 评分标 `TVmaze x/10`。
  - 电影：Wikipedia 搜索 + Wikidata P31/P577 校验作品类型与年份；中文简介/海报；无评分则省略。
  - 同目录多电影：逐文件解析并写入 `movieWorks[path]`，文件夹头显示“影片文件夹 · N 部”，行内显示各自标题/简介/年份。
- 实测 `Attack on Titan (2013)/Season 01/Shingeki no Kyojin - S01E01/E02`：中文名“進擊的巨人”、2013、TVmaze 8.9/10，E01/E02 不同英文简介与 TVmaze 剧照；`.zh.ass` 不参与匹配。
- 手动「重新匹配」打开片名/年份编辑，保存到 `webdav-matches.json`（按 source|path），清缓存后重试；用于纠正错配。
- 快速换目录由 Browser 的 `loadToken` 丢弃旧响应；资料异步加载，目录和播放不被阻塞。

## 3. 首页继续观看

- `ContinueWatching.visible`：过滤 finished/零进度/重复，按 `seriesKey`（Jellyfin seriesID 或 WebDAV 相对剧目录）保留最近一集，再按 `lastPlayedAt` 倒序取 4。
- 完整历史由“查看全部”sheet 读取 `PlaybackStore`，折叠不删除记录/不覆盖进度。
- 缩略图：Jellyfin 当前 item 图片；WebDAV 已缓存/懒加载的本集 still；本地或缺失时读播放中 2 秒截取的 `RecentThumbnails` 帧；最后渐变占位。首页只发图片请求，不打开视频。
- 17 条 fixture 验证 4 项、排序、已完成/零进度/重复排除、同剧一集；重启后缓存仍可读。

## 4. 点击继续观看 → 加载页

- `AppRoute.loading` + `PlayerLoadingView`：片名、集号、来源、取消/重试/返回；`resume()` 先切路由再异步调用 open 系列。
- `beginPlaybackSession` 在 resume 时自增，取消/新点击使旧请求过期；播放器成功后才切 `.player`。
- 3 秒 PROPFIND 延迟下截图加载页；取消回首页；缺密码/路径不存在显示错误页+重试；恢复时使用记录中的 mediaSourceID/原位置。
- 加载期间窗口、取消按钮与 Cmd-Tab 正常；首页已被加载页替换。

## 5. 移除进度同步

- 删除 `ProgressSync.swift`、同步设置 Section、CA 文件导入、`--sync-progress` 和 `OPENFUSE_SYNC_*` 读取路径、同步验收脚本。
- 首次启动 `purgeLegacySyncConfiguration` 清理 `openfuse.sync.url/ca/token`、`sync-token` Keychain 与 `sync-ca.pem`；不触碰播放记录、字幕偏移、Jellyfin 进度。
- 旧 defaults + env 实测：本地监听未收到任何请求，defaults key 被删除。
