# 0.8.2：Jellyfin Trickplay、预取与缩略图基准

- `JellyfinTrickplay` 模型/context/Trickplay URL；ThumbnailProvider 按 media source 的 interval 计算 index，按 tile 网格裁切，写入同一磁盘缓存；无 Trickplay 时回退独立解码。
- 首帧稳定后低优先级预取当前位置 ±15/30 秒；`OPENFUSE_DISABLE_THUMB_PREFETCH=1` 可关闭；主播放 buffering 时停止后续预取。
- 30 冷 + 30 热 benchmark：本地冷 P50 164/P95 209 ms；盘 P50 0/P95 4 ms；热 P95 0 ms。
- Jellyfin Inception（有 Trickplay）30 样本：`thumbnailTrickplayHits=5`，P50 0/P95 163 ms；Fargo E01（无 Trickplay）`trickplayHits=0`，独立解码 P95 171 ms。
- 未实现跨请求时段合并的显式队列统计；快速横扫仍由 RequestBox 取消旧任务、串行队列优先最新请求。
