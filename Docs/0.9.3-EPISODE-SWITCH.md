# OpenFuse 0.9.3 · 换集后右键/空格暂停修复

基线：`0.9.2`（`d6268ee`）。本轮只修一个回归缺陷：在播放页面换集之后，右键任意位置或按空格都暂停不了正在播放的新视频。

## 现象与复现

1. 播放本地夹具 `Fixtures/generated/openfuse-fixture.mkv`。
2. 在播放器里打开「同文件夹视频」选到 `video.mkv`（或直接打开另一个文件）完成换集。
3. 在画面任意位置右键，或按空格：画面继续播放，没有暂停。

修复前的实测报告（`--folder-list --folder-select video.mkv --report ...`）：

```json
{"file": "…/Fixtures/generated/video.mkv", "paused": false, "userPaused": false}
```

不换集的同一操作是 `paused: true`，所以问题只出现在换集之后。`OPENFUSE_DEBUG_HITS=1` 下右键监视器打印：

```text
[right] DIAG captured=openfuse-fixture.mkv current=video.mkv
```

## 根因

`PlayerView` 在 `onAppear` 里安装 `NSEvent` 本地监视器（`.keyDown` / `.rightMouseDown`），闭包直接引用视图的 `@ObservedObject var player`，也就是把安装时的那一个 `PlayerModel` 按值捕获进闭包。

`startPlayer()` 换集时会新建一个 `PlayerModel`（新 mpv engine）并替换 `AppModel.player`，但 `route` 始终是 `.player`，`RootView` 里的 `PlayerView` 结构位置没变：SwiftUI 保留视图身份与 `@State`，`onAppear` 不再触发，监视器也不会被重新安装。于是 `guard rightClickMonitor == nil else { return }` 让旧闭包一直存活，右键/空格持续调用**已 `stopAndClose()` 的旧引擎**，`player.isPaused` / `userPaused` 写在旧模型上，新引擎毫无反应。受影响的还有 ↑/↓ 音量、←/→ 快进快退、Esc、⌘3 和键盘活动记录。

顺带排除了两条常见猜测：`NSApp.keyWindow?.firstResponder` 在换集后是窗口本身（不是 `NSTextView`），窗口/keyWindow 判断也仍然成立。

试图用 `.onChange(of: ObjectIdentifier(player))` 重新绑定也不行：实测该 action 闭包捕获的是**旧视图值**（打印 `player=openfuse-fixture.mkv` 而 `AppModel.shared.player=video.mkv`），重绑后仍然指向旧模型。

## 修复

不再在闭包里捕获 `PlayerModel`，改为在**事件到达时**从权威来源解析当前在屏剧集：

```swift
let model = AppModel.shared
guard model.route == .player, let player = model.player else { return event }
player.togglePlayPause(userInitiated: true)
```

`installRightClickMonitor()` 与 `installKeyboardMonitor()` 都改成这种延迟绑定，因此换集、自动连播下一集、加载中改选另一集、`resume()` 经 `.loading` 回来等所有路径上，右键和键盘快捷键都作用于当前引擎。保留 `route == .player` 判断，避免残留监视器在首页吞掉事件；`OPENFUSE_DEBUG_HITS=1` 的日志现在会打印 `target=`，方便直接核对事件落在哪一集。

改动仅 `Sources/OpenFuseApp/PlayerView.swift`（+18 行），不改动播放器布局、面板几何或 mpv 管线。

## 验证

- `swift test`：全部通过（0 失败）。
- 新增 `Scripts/run-episode-switch-pause.sh`：6 个用例，用真实 CGEvent 右键与 AppleScript 按键驱动，覆盖
  - 不换集 + 空格 / 右键（基线）；
  - 选集面板换集 + 空格 / 右键；
  - 直接打开另一文件换集 + 空格；
  - 换集后 ↓ 音量键（证明同一处缺陷影响的其他快捷键也修好）。

  每个用例校验 `file`、`paused`、`userPaused`，音量用例校验 `volume=95` 与 `currentVolumeProperty=95.000000`：

```text
ok   folder-switch-space: episode on screen: video.mkv
ok   folder-switch-space: space pauses after switch: True
ok   folder-switch-right: right pauses after switch: True
ok   direct-switch-space: space pauses after switch: True
ok   folder-switch-volume: mpv volume of new engine follows: 95.000000
PASS: right-click / space / volume keys follow episode switches
```

- `Scripts/run-player-interactions.sh`：原有右键区域/全屏、音量键、缓冲中暂停验收保持 PASS。
