## 下一批可执行工作

1. Jellyfin Library Mode 与聚合海报库：条目/季集/版本模型、TMDB 识别、聚合首页、搜索、继续观看/最近添加（M3）。
2. 真实 Jellyfin：独立测试账号验证 HTTPS/反向代理、转码、外挂字幕、多用户；缺账号的组合标「待验证」。
3. 真实 OpenList：独立测试账号验证登录、限流、签名跳转与目录规模；重定向凭据改为本机代理。
4. 轨道映射改为显式 MediaStream Index；暂停/拖动立即回写进度。
5. 远程首帧与拖动分段计时；本地/LAN 10% 中位数目标。
6. 真机 5.1 接收器与 Infuse 对照：需要设备与安装包时逐项登记「待验证」，不阻塞其他工作。

## 已知风险

- libmpv/FFmpeg 的许可与打包；当前依赖 Homebrew。
- 窗口快照不包含 OpenGL 层，UI 自动比对需要另建渲染抓帧。
- 无 Infuse 安装与测试账号，参照矩阵无法闭环。
