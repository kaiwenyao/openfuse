# OpenFuse 阶段交接（2026-11-20）

阶段分支：`stage-2026-11-20`。基线参照：Infuse 8.5.10（含 Pro，未安装，所有对照均标“待验证”）。

## 1. 当前结论

OpenFuse 已从空仓库推进到可在五端构建、在 Mac/iPhone/iPad/tvOS/visionOS 模拟器运行的产品骨架，三条优先路径均有真实服务验收：

- 本地 MKV：libmpv/OpenGL，HEVC Main10、E-AC-3 5.1、双语 ASS/SRT、seek/字幕同步/续播。
- OpenList WebDAV：真实 OpenList Docker `/dav`，Mac+iPhone 扫描、直放、seek、Range、远程字幕、进度。
- Jellyfin：真实 12.4 Docker；Mac 直连 MP4/MKV、seek、字幕、进度；iPhone MKV HLS 1080p 转码；多用户进度/权限隔离、用户切换。
- SMB：真实 Samba SMB3、签名/加密、1.4GB/2.4GB 大文件、32/64 并发、周期长稳。
- 跨设备：HTTP/HTTPS + Bearer + CA 固定；Mac→iPhone 续播；Mac/iPhone 设置 UI/持久化。
- 音频：BlackHole 2ch 实际录到回放输出，设备路由静音对照通过。
- 平台：Mac 主应用；iPhone/iPad 自适应；tvOS 实际出画；visionOS 全沉浸/3D 控件。

仍**不能**声称完成的目标：物理 5.1/AVR/HDMI、HDR 实际测量、真实 Infuse 同机对照、真实 Baidu/CloudKit/Trakt 账号、真实 Vision Pro/Apple TV/iPad/iPhone、小时级 SMB soak、DFS/域。

## 3. 构建与启动

```bash
cd /Users/ykw/Documents/openfuse

# 依赖
brew install mpv
Scripts/install-libsmb2.sh
Scripts/make_fixtures.sh          # 60s 主样片 + 手机 MP4
Scripts/build-app.sh              # Mac
open build/OpenFuse.app

# 手机/平板/tvOS/visionOS
Scripts/build-ios.sh 'platform=iOS Simulator,id=<UDID>' build/ios Debug
xcodebuild -project OpenFuseMobile.xcodeproj -scheme OpenFuseTV ...
xcodebuild -project OpenFuseMobile.xcodeproj -scheme OpenFuseVision ...

# 自包含 Mac app
Scripts/package-app.sh
```

## 5. 未完成与可复现差异

1. **物理 5.1/AVR/HDMI/人耳**：无 16ch 虚拟驱动安装权限（需 sudo/重启），只验证 2ch downmix 实际输出。
2. **HDR 实测**：有 HDR10 素材、EDR 显示/tonemap 参数，但无色彩计/EDR 采集测量。
3. **Infuse 8.5.10 同机对照**：参考客户端未安装，布局/默认设置/图标/动效仍缺逐项对照。
4. **真实百度网盘**：OpenList 使用 Local storage；百度账号/云跳转限速未测。
5. **真实 CloudKit/Trakt 账号**：CloudKit 需签名 entitlement/账号；Trakt 仅夹具。
6. **真实设备**：iPhone/iPad/Apple TV/Vision Pro 均为模拟器；真机性能/遥控/空间音频未测。
7. **SMB DFS/域/Kerberos/小时级 soak**：未测；>64 并发未测。
8. **UI 自动化**：Jellyfin 切换面板点击、CA fileImporter、iOS 相册导入未自动化。
9. **iPad 冷启动约15s**、autoplay 测试钩子在 iPad 未触发；用户点击路径未自动化。
10. **tvOS** 仅 bundled sample，远程来源/同步/字幕设置未接入；布局单海报大片留白。
11. **Jellyfin HTTPS/4K/多用户并发**未测。

## 6. 下一阶段优先级

1. **真机/参考对照**：装 Infuse，按 `PARITY.md` 逐项采样布局、默认值、图标、播放器控件、字幕样式。
2. **物理音频/HDR**：有权限的机器安装 BlackHole 16ch/连接 AVR，验证 6ch 分离与 HDR 亮度。
3. **真实账号**：百度网盘 OpenList、Trakt、CloudKit、Jellyfin HTTPS。
4. **平台补全**：tvOS 远程来源/同步/遥控导航；iPad 横屏/多任务/首启优化；visionOS 真机。
5. **稳定性**：小时级 SMB soak、>64 并发、DFS/域。
6. **自动化**：UI 点击/fileImporter/Keychain、真机 smoke。
